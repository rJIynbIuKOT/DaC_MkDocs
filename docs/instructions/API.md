# Концепция API

API (Application Programming Interface) — описание способов взаимодействия одной компьютерной программы с другими. Такое взаимодействие происходит постоянно, когда вы пользуетесь какими-то программами, сервисами или сайтами, даже если вы этого не замечаете:

- любая оплата в интернете идет через API платежной системы;
- регистрация и авторизация на сайте или сервисе с помощью сторонних аккаунтов;
- отправка сообщений из игр, программ или интернет-магазинов в вашу любимую социальную сеть или личным сообщением другу в мессенджере.

API можно сравнить с контрактом или договором в реальной жизни. Договором между двумя сторонами, например, на ремонт техники:

- Ваши обязанности — предоставить сломанное оборудование и заплатить определенную сумму.
- Обязанности мастера — починить или заменить сломанную деталь.

Другими словами, API это контракт, который предоставляет программа для взаимодействия с ней. И в этом контракте сказано: «Ко мне можно обращаться так и так, а я обязуюсь делать то и это».

И даже если у программы нет интеграции с другими системами, в ней все равно есть API для общения и взаимодействия между элементами внутри себя.

API включает в себя:

- операцию, которую можно выполнить;
- данные, которые поступают на вход;
- данные, которые отдаются на выходе, то есть результат или сообщение об ошибке.

Если вы соприкасались с программированием или хотя бы делали отчеты в Excel, то заметите, что все это очень похоже на описание функции: данные на входе, данные на выходе, и какая-то магия, которая преобразует одно в другое. Так и есть, API — это набор функций. Это может быть одна функция, а может быть много. И в зависимости от назначения определенного API разработчики решают, сколько функций оно будет содержать.
